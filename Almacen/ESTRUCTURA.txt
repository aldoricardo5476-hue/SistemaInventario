EJECUCIÓN
═══════════════════════════════════════════════════════════════

Comando principal:
  java -cp bin App

O usando el script:
  ./run.sh

El programa inicia con un menú principal que permite:
  1. Acceso como CLIENTE (Realizar compras)
  2. Acceso como ADMINISTRADOR (Gestionar inventario)
  3. Salir del sistema

FLUJOS PRINCIPALES
═══════════════════════════════════════════════════════════════

FLUJO 1: COMPRA CLIENTE
────────────────────────────────────────────────────────────

Cliente accede como CLIENTE
         ↓
    PASO 1: Ve 5 productos con stock
         ↓
    PASO 2: Selecciona productos (valida stock)
         ↓
    PASO 3: Revisa carrito (puede editar)
         ↓
    PASO 4: Elige método de pago (3 opciones)
         ↓
    PASO 5: Confirmación + Número pedido (#000001)
         ↓
Sistema actualiza inventario automáticamente
Registra venta en historial con fecha/hora
Verifica si stock llegó a nivel crítico
Genera alerta si es necesario


FLUJO 2: ADMINISTRACIÓN INVENTARIO
────────────────────────────────────────────────────────────

Admin accede como ADMINISTRADOR
         ↓
    Menú con 9 opciones:
    
    1. Ver Inventario → Muestra estado actual (🟢🟡🔴)
    2. Registrar Venta → Actualiza stock
    3. Registrar Surtido → Reabastece producto
    4. Ajuste Físico → Sincroniza almacén
    5. Notificación → Productos que necesitan reabastecimiento
    6. Pedido Proveedor → Realiza compra mayorista
    7. Reporte Movimientos → Historial completo
    8. Reporte Ventas → Análisis de ingresos
    9. Reporte Pedidos → Historial de inversión

NIVELES DE STOCK

   Estado: Considerar reabastecimiento

   Estado: ALERTA INMEDIATA

TIPOS DE MOVIMIENTOS REGISTRADOS
═══════════════════════════════════════════════════════════════

INGRESO
  → Nuevo producto agregado al inventario
  → Registrado al inicio

VENTA
  → Cuando cliente compra
  → Descuenta stock automáticamente

SURTIDO
  → Reabastecimiento de proveedor
  → Aumenta stock disponible

AJUSTE_POSITIVO
  → Conteo físico > sistema
  → Se encontraron más productos

AJUSTE_NEGATIVO
  → Conteo físico < sistema
  → Faltaron productos

Cada movimiento incluye:
  ✓ Fecha exacta (dd/MM/yyyy)
  ✓ Hora exacta (HH:mm)
  ✓ Producto
  ✓ Cantidad
  ✓ Tipo de operación
